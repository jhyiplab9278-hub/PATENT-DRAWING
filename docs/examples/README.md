# 블록도 디자인 참고 자료

이 디렉터리의 이미지는 특허 도면용 블록도 편집기의 레이아웃과 표현 방식을 검토하기 위한 참고 자료다.

## 우선 개발 범위

첫 구현에서는 블록도 제작 기능을 우선한다.

- 블록 생성, 이동, 크기 조절 및 텍스트 편집
- 블록 중첩과 컨테이너 표현
- 직선 및 직각 연결선과 화살표
- 실선, 점선 및 일점쇄선 전환
- 도면부호와 지시선 배치
- 문서형 데이터 블록과 복수 시트 표현
- 흑백 특허 도면 스타일 출력

## 참고 이미지

- `block-diagram-layout-reference.png`: 구성 요소가 중첩된 시스템 블록도와 복수 연결선 참고
- `flowchart-layout-reference.png`: 시작·종료 터미네이터, 처리 단계, 수직 화살표 및 단계부호 참고

참고 이미지는 편집기의 디자인과 기능을 정의하기 위한 자료이며, 특정 도면의 기술 내용을 그대로 복제하기 위한 자료가 아니다.

## 재현 기준

- 블록의 형태, 테두리 굵기, 모서리 반경, 간격과 정렬은 수치화하여 재현한다.
- 글꼴 종류, 크기, 자간, 행간과 정렬을 요소 속성으로 저장한다.
- 원본 글꼴이 확인되고 사용 가능한 경우 해당 글꼴을 기본 프리셋으로 제공한다.
- 이미지에서 글꼴을 확정할 수 없는 경우 가장 가까운 설치 글꼴로 맞추고 사용자가 교체할 수 있게 한다.
