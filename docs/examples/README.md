# 블록도 디자인 참고 자료

이 디렉터리의 이미지는 특허 도면용 블록도 편집기의 레이아웃과 표현 방식을 검토하기 위한 참고 자료다.

## 우선 개발 범위

첫 구현에서는 블록도 제작 기능을 우선한다.

- 블록 생성, 이동, 크기 조절 및 텍스트 편집
- 블록 중첩과 컨테이너 표현
- 직선 및 직각 연결선과 화살표
- 실선, 점선 및 일점쇄선 전환
- 도면부호와 지시선 배치
- 문서형 데이터 블록과 복수 시트 표현
- 흑백 특허 도면 스타일 출력

`block-diagram-layout-reference.png`는 디자인 참고용이며, 특정 도면을 그대로 복제하기 위한 자료가 아니다.
